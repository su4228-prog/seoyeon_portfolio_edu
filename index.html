03 생성형 AI 워크플로우 설계

생성형 AI 활용 과정을 단계별로 구조화해, 누구나 따라 할 수 있는 흐름으로 만듭니다

프롬프트 설계단계별 워크플로우AI 도구 활용
AI 콘텐츠 자동화 · Google Opal

AI 기반 비주얼 콘텐츠 제작 자동화

Google Opal 워크플로우 3종 — 카드뉴스·제품 연출컷·스토리보드
Google Opal · Gemini · Nano Banana Pro

카드뉴스·제품 연출컷·드라마 스토리보드를 자동 생성하는 워크플로우를 만들어, 기획부터 이미지 제작까지 하나의 흐름으로 연결했습니다.

3종소재 제작 워크플로우
5장카드뉴스 자동 생성
3컷제품 사진 1장으로 연출컷
맡은 역할
  • 주제·레퍼런스 분석 → 카피라이팅 → 카드뉴스 5장 제작 과정 자동화
  • 제품 이미지 입력만으로 콘셉트가 다른 연출컷 3개를 만드는 워크플로우 구현
  • JSON 기반 프롬프트 구조화와 생성 단계 분리로 결과물 일관성 개선
카드뉴스 앱 ↗제품 연출컷 앱 ↗스토리보드 앱 ↗
결과물
워크플로우
  1. 주제·레퍼런스 입력
  2. 카피라이팅 문장 생성
  3. 카드별 프롬프트 생성 (JSON)
  4. 디자인 이미지 5장 생성
결과물
워크플로우
  1. 제품 사진 업로드
  2. 연출 콘셉트 3종 프롬프트 (JSON)
  3. 연출컷 이미지 생성
  4. 갤러리로 결과 출력
결과물
워크플로우
  1. 대본·등장인물 입력
  2. 인물 설정 정리 (JSON)
  3. 장면 프롬프트 + 스타일 지정
  4. 스토리보드 컷 생성
